Issues unresolved

DLSS upscaling doesn't work properly in game's release version

Game seem to be targeting wrong output resolution when enabling DLSS upscaling and doesn't select modern upscaling model from DLSS 4.5 v310.6.0 SDK it shipped with.[2][3]
DLAA and DLSS Quality are the only DLSS presets available which upscale to the actual display resolution but both are using DLSS 3.7 model E while doing so.
DLSS Balanced and Performance are both upscaling to a resolution below monitor's native, with only Performance using DLSS 4.5 model M.
Use "Custom" upscaler quality option instead of using DLSS presets as a workaround[4]
  1. Set DLSS Upscaler Quality option to "Custom".
  2. Set Resolution Scale slider to 100%. This will force the game to upscale to your monitor native resolution.
  3. Maximum Dynamic Resolution slider will control game's rendering pre-upscale resolution.
    1. 25% on this slider would be equivalent to Performance preset.
    2. 33% is close to Balanced preset.
    3. 45% is close to Quality preset.
The game will still use DLSS 3.7 model E with this workaround. You can force a different, modern DLSS model with Nvidia app or Nvidia Profile Inspector.
