Elden Ring is an ARPG developed by FromSoftware and published by Bandai Namco Entertainment. It is the first installment in the Elden Ring series.

Unveiled at the E3 2019 in June 2019, it was released on February 25, 2022.

Issues unresolved

Random stutter and frame rate drops in open areas

The game appears to suffer from stuttering issues, particularly during combat in open world areas, likely caused by background loading and shader compilation mismanagement.[5][6]
Potential fix for stutter and frame rate drops[citation needed]
  • The game is a DirectX 12 title with no shader precompiling. The game will stutter less the more it's played, as it saves its shaders on the system. Note that every time the drivers are updated, the shader stutter will begin again.
  • Disable USB selective Suspend in Power Plan on the Windows Control Panel. Using Windows Search, look for 'Power Plan', select 'Change advanced power settings'. A Power Options window should open, click [+] on 'USB Settings', then click [+] on 'USB selective suspend setting' and change the 'Setting:' to Disabled.
  • Hyperthreading (Intel) or SMT (AMD) seems to be a major cause for freezing/stuttering on CPUs with more than 8 cores. It is recommended to disable Hyperthreading/SMT in the BIOS settings, or by using an application such as Process Lasso.
  • Forcing Vsync off in the GPU control panel for the game or globally, substantially reduces stutters at the cost of introducing tearing. Setting Vsync to fast turns it off and reduces tearing to imperceptible levels.
  • Disable Microsoft Device Association Root Enumerator in Device Manager. To find this, go to the Control Panel, locate Software devices, Right click Microsoft Device Association Root Enumerator and click Disable Device.
  • Disable Steam Overlay by Right clicking Elden Ring in the Steam Library, choose Properties, Uncheck Enable the Steam Overlay while in-game.
  • The game may occasionally freeze up for several moments at a time when using a controller. A mod that fixes it can be found here. Uninstall all Microsoft Store and PC Game Pass games that are located in the WindowsApps folder. Update the Xbox App via the Microsoft Store. Reinstall the games via the advanced installation settings located in the General section to another custom game folder. If the Xbox app does not show the advanced installation settings, uninstall it, then reinstall it from the Microsoft Store. Some games, such as Sea of Thieves, do not currently support advanced installation. If all else fails, uninstall the Xbox app and all Xbox games. Further explanation here.
  • Use Maximum Performance and reduce Input Lag setting on Nvidia GPUS. On the Nvidia Control Panel go to 'Manage 3D Settings', click on the 'Program Settings Tab', then 'Add' and select Elden Ring from the list of programs or 'Browse' and you can look for it in the drive you installed it. Once added look for 'Power management mode' and change it into 'Prefer maximum performance'. In the same window look for "Low Latency Mode" and select 'On' or 'Ultra'. The 'Ultra' setting can have stutter problems on modest hardware depending on the game while 'On' is more dependable.
  • Disable core 0 using Task Manager or Process Lasso on 'eldenring.exe' (Easy Anti-Cheat blocks modification of the core affinity, usable only for offline mode).

Issues fixed

Controller not detected when playing via Steam Input

Enable desktop configuration[citation needed]
  • Go to Steam > Controller > Desktop Configuration to open the Steam Controller Configurator.
  • Select 'Browse Configs' and apply a desired configuration to use in-game (note: this will also enable the controller in this configuration on desktop).
  • Exit the Steam Controller Configurator.
  • In the Library, right-click on Elden Ring and select 'Properties...'.
  • In the controller category, ensure Steam Input is enabled.

Fullscreen mode is limited to 60 Hz

Fullscreen mode defaults to 60 Hz, even if the screen refresh rate is set higher than that.
Run the game in Borderless Windowed or see Modifications to remove the limitation[citation needed]

White screen with cursor followed by a crash to desktop after launching the game

The game seems to require DX12 features not available on some older versions of Windows.
Update to version 21H1 (or at least version 1909)[citation needed])
Process Lasso CPU Affinity feature[citation needed])
  • While the game seems to work well with process lasso priority class feature it may not start with Affinity enabled, disable all affinities to fix the crashes and maybe switch to CPU sets ( a ‘softer’ form of CPU Affinities that only "suggest" to the OS which core to use).

Crash at Bandai Namco logo

Turn off Steam Overlay from Steam (Steam->Settings->In-game->Enable steam overlay [OFF])[citation needed]

Crashes on Radeon Vega 8 Graphics iGPUs

Enable Radeon Anti-Lag[citation needed]
  1. Launch AMD Software and go to Settings > Graphics.
  2. Set Radeon Anti-Lag to Enabled.

Notes

Note that in many scenarios, anti-lag can cause an input lag increase across all games.[7]

Anti-aliasing setting resets after relaunching the game when set to "Off"

Manually fix the configuration and set to read-only[8]
  1. Edit the GraphicsConfig.xml in the configuration folder and set the "Antialiasing" option to "DISABLE".
  2. Set the file to read-only: Properties > Check "Read-only" > Apply > OK.

Notes

When setting the "Anti-aliasing" option to "Off" in the game settings, the value is set to "OFF" in the configuration file instead of "DISABLE", which would have been the correct value. At launch, the game detects the wrong value and resets it to the default anti-aliasing value (High).
This bug has been fixed as of patch 1.13.

Anti-cheat Easy Anti-Cheat

Easy Anti-Cheat

The embedded Easy Anti-Cheat component prevents unknown third-party tools from injecting themselves in the game. This protection can be disabled, which allows the use of said tools.
Online play will be disabled when Easy Anti-Cheat is disabled.
At launch included version of Easy Anti-Cheat was not compatible with CET, which is enabled by default on Windows 11 and some Windows 10 configurations with Zen3 (Ryzen 5000+) and Intel 11th Gen+ CPUs.[9] This should have been fixed with 1.03 game update.
Use Elden Ring EAC Toggler[citation needed]

Notes

This tool will make start_protected_game.exe launch eldenring.exe, so the latest game version will always be used and Easy Anti-Cheat will be disabled no matter how the game is launched.
Run through eldenring.exe[10]
  1. Go to <path-to-game>\Game\.
  2. Create steam_appid.txt and write 1245620 inside the file. Don't forget to save it.
  3. Run the game through eldenring.exe. It will launch directly and still have full integration with Steam.

Notes

Deleting or renaming start_protected_game.exe located in <path-to-game>\Game\ and then renaming eldenring.exe to start_protected_game.exe, allows the game to be directly launched through Steam.
Optionally, add eldenring.exe as a non-Steam game or create a shortcut on the desktop.

General

Frame Generation & Super Resolution for ELDEN RING

  • Supports upscaling with DLSS, FSR and Intel XeSS.
  • Supports Frame Generation.
  • Supports overriding the Fullscreen mode and running borderless while the game thinks it's fullscreen. This makes it possible to remove the 60Hz refresh limitation with other mods and Vsync off, allowing HDR support with no screen tearing.
  • Can be run alongside Reshade with add-on support.
  • Can be used to force the color space to HDR, getting rid of washed out colors bug with HDR on.

Flawless Widescreen

  • Supports various widescreen aspect ratios without resolution limitations.
  • Adds FOV controls and allows vignette and chromatic aberration removal.
  • Increases the distance for full rate animations, unlocks the frame rate and removes the 60 Hz refresh limitation in Fullscreen mode.

FPS Unlocker and more

  • Unlocks the frame rate.
  • Removes forced 60Hz limit in fullscreen.
  • Adds FOV controls.
  • Disables camera auto rotate adjustment on movement (intended for mouse users).
  • Disables centering of the camera (cam reset) on lock-on if there is no target.
  • Adds support for widescreen monitors.
  • Adds global game speed modifier.
  • Disables losing Runes on death.

Elden Ring Proton Patcher 2

  • Sets a custom frame rate limit.
  • Disables losing runes upon death.
  • Removes black bars.
  • Removes the vignette overlay.
  • Disables chromatic abberation.
  • Fixes low frame rate animations at screen edges and of distant entities.
  • Skips intro logos.
  • Removes the 60Hz limit in fullscreen.
  • Center camera to player
  • Faster respawn
  • Disable the camera reset when trying to lock-on with no target in range
  • Disable camera auto rotate

Elden Ring Mods by techiew

  • Unlocks the frame rate.
  • Fixes the camera.
  • Adds FOV controls.
  • Adds game pausing.
  • Disables losing runes upon death.
  • Removes black bars.
  • Removes the vignette overlay.
  • Disables chromatic abberation.
  • Increases animation distance.
  • Skips intro logos.
