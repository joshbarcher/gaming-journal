# Discovery Page
- Graph with centralized node "What are you feeling like?"
- Leads to adjacent nodes (genres, game length, favorites, unfinished games)
- These open up into subtopics as well, exploring the graph, which leads to games
- At any point, the filter can then be stopped and show games found, or even lead to a single game
- Current nodes should be brightly highlighted, next nodes less so
- You should be able to back up one level
- The text + visuals should be gamified (think bouncing/jiggling/animated text in slay the spire or balatro, but less wild)
